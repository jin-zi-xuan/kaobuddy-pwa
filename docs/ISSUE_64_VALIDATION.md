## 已完成

- 备份界面：JSON 下载、导入预检、默认合并保留本地记录、替换前下载旧数据；七张表使用同一事务，失败回滚。
- 学习进度：速背结果和卡片轮次进入 IndexedDB，随备份导出；普通模块保存不会覆盖最新学习会话。切项目和恢复备份会使旧异步会话失效。
- 资料：RTF 正确解码中文；无正文 PDF 不再假成功；手写 PDF 所有页面分批视觉识别，包括混合文字/扫描页。每批最多六页并释放渲染资源。
- 后端：校验全部 DNS 结果、固定连接 IP、保留 TLS 域名校验，重定向逐跳检查。AI 私网访问必须显式开启，视频/字幕不放行。仅允许 PDF 所需的 WebAssembly 编译，不开放 JavaScript eval。
- 离线：构建生成内容版本和完整预缓存清单。更新由用户点击后执行，未刷新的旧标签页仍可读取旧哈希资源。
- 体验：手机项目菜单折叠、头部压缩、六个导航可见、过期考试显示已结束；文档解析和 PDF 导出按需加载。
- 工程：前端测试接入 npm test 与 CI；同步文档请求流向/入口/版本；依赖安全补丁更新后 npm audit 为零。

## 边界

真实模型 OCR/生成质量和 Windows 打包本轮没有调用或重新打包。OCR 批处理及异常链路使用隔离测试验证，未消耗真实 API 额度。pdfjs 内部仍可能吞掉个别损坏图像的解码错误；此次消除了确定的 WASM CSP 阻断，不能保证所有损坏 PDF 均可识别。

离线首次安装约需缓存 4.6 MB。为了旧标签页安全，有窗口时保留旧版本缓存，无窗口激活时回收；长期不关页面会占用多个版本的缓存。文档/导出分包仍有构建大小提示，主入口已从约 1.62 MB 降到约 0.53 MB（gzip 约 470 KB 降到 163 KB）。
