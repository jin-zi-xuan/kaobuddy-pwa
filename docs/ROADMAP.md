# Roadmap

## v2.0.0 Windows Desktop

目标：把 KaoBuddy 交付为可独立安装、每天直接打开的 Windows 考研搭子。

- Rust + Dioxus Desktop 原生窗口。
- NSIS `.exe` 当前用户安装包。
- Windows 本地文件持久化，不依赖浏览器或 localhost。
- 资料、计划、课程、练习、模考、错题和速背闭环。
- B 站官方播放器在桌面 APP 内播放。
- OpenAI-compatible 模型由原生 Rust 直接调用。

## v2.1.0

目标：让资料与复盘更完整。

- 强化 PDF、DOCX 和扫描笔记的原生解析。
- 给资料库增加搜索、标签和来源定位。
- 完成模块讲解、练习、卡片和批改的桌面交互。
- 增加错题趋势和阶段模考对比。
- 增加 JSON 数据导入导出。

## v2.2.0

目标：提高正式发布质量。

- Windows 代码签名和自动更新。
- 安装包升级与数据迁移验证。
- 崩溃日志的本地导出与隐私说明。
- 完整键盘导航和无障碍检查。
